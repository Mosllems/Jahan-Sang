# جهان سنگ (Jahan Sang)

وب‌سایت معرفی شرکت سنگ ساختمانی، ساخته‌شده با Django: مقالات، نمونه‌پروژه‌ها، موجودی انبار (سنگ و ابزار)، پروفایل کاربران و چت‌ویجت.

## اجرای پروژه (با Docker)

```bash
git clone <آدرس-مخزن>
cd Jahan_Sang

cp .env.example .env          # سپس مقادیر داخل .env را ویرایش کنید
docker compose up --build     # دیتابیس و سایت بالا می‌آیند و migrate خودکار اجرا می‌شود
```

سایت روی <http://127.0.0.1:8000> در دسترس است.

### محتوای نمونه

دیتابیس در ابتدا خالی است. برای ساخت چند مقاله، پروژه و سنگ نمونه:

```bash
docker compose exec backend python manage.py load_demo
```

این دستور چندبار اجرا شدنش مشکلی ندارد (موارد تکراری ساخته نمی‌شوند).

### ورود به پنل مدیریت

```bash
docker compose exec backend python manage.py createsuperuser
```

سپس به <http://127.0.0.1:8000/admin/> بروید.

## نکته‌ها

- عکس‌هایی که از ادمین آپلود می‌شوند در پوشه‌ی `media/` ذخیره می‌شوند و عمداً داخل گیت نیستند.
- ادیتور متن مقالات و توضیحات پروژه‌ها CKEditor 5 است و متن را به‌صورت Markdown ذخیره می‌کند.
  برای نمایش در قالب‌ها از فیلتر `{{ text|markdown }}` (`{% load markdown_extras %}`) استفاده کنید.
